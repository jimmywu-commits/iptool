注意事項
  1. 本工具之「色彩檢查功能」僅供 2D 版本 (純色、有黑框線) 之蝦小編使用，若導入 2.5D 或是 3D 版本蝦小編會有顏色無法準確偵測之情形發生。
  2. IP 角色若穿著非規範之「特殊造型服裝」請聯繫對應窗口人工審核。
  3. 本工具僅供網頁色彩Hex碼檢查 (RGB)，不適用於印刷品校色 (CMYK)，印刷品校色請核對「實體樣品」或是「色票」。
  4. 蝦小編規範可參閱內部教學中心。
